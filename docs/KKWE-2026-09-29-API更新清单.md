# 2026-09-29 KKWE API 更新清单

依据：本次同步前后的 YDWE/jass 四组 API 声明差异；中文名称引用本次同步的 MPQ/kkapi 和 MPQ/dzapi2 下的 action.txt、call.txt、event.txt。正式/PRE 状态按声明所在文件判断。

新增 86 个接口，其中 81 个位于 KKPRE、5 个位于正式 API；125 个接口由 KKPRE 转入 KKAPI；删除 0 个接口。

验证：War3Lib `VERSION_UNITTEST`（CardFlipAnim）和 Xlimon `VERSION_ALPHA` 均通过 vjassc 编译；`DzFrameGetName`、`DzIsWindowActive` 只在 BlizzardAPI 登记，没有重复注入警告。
