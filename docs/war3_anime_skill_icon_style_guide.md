# War3 二次元技能图标风格规则

> 用途：后续制作 Warcraft III / War3 技能图标、天赋图标、被动图标、装备主动图标时复用。  
> 核心目标：**64×64 小尺寸下依然清晰、醒目、能一眼看懂技能属性与释放感。**

---

## 1. 风格定位

这套图标风格可以概括为：

**二次元手游技能图标 + 高饱和能量特效 + 暗色背景 + 强剪影/强符号 + 爆发式光效。**

不是 War3 原生那种厚重写实油画风，而是更偏：

- Anime fantasy skill icon
- Mobile game ability icon
- Cel-shaded energy effect
- Neon glow spell icon
- High contrast readable icon

视觉关键词：

**高饱和、霓虹、发光、速度感、爆发、剪影、符号化、强对比、低细节高识别度。**

---

## 2. 适用范围

适合用于：

- War3 技能按钮
- 英雄技能图标
- 被动技能图标
- 天赋图标
- 装备主动效果图标
- 魔法书内技能图标
- 64×64 / 128×128 小尺寸 UI 图标

不太适合用于：

- 大尺寸写实插画
- 复杂装备立绘
- 需要大量文字信息的 UI
- 需要厚重材质感的传统暗黑风图标

---

## 3. 尺寸与可读性原则

War3 图标通常显示很小，所以第一原则是：

**宁可简单、夸张、清楚，也不要复杂、精细、写实。**

制作时应遵守：

- 主体占画面 **70% 以上**。
- 主体轮廓必须清楚。
- 不要塞太多小元素。
- 不要添加文字。
- 不要使用低对比灰色主体。
- 不要让背景和主体颜色太接近。
- 最亮区域可以接近纯白，用来制造技能冲击力。
- 四角可以暗，中心必须亮。
- 缩小到 64×64 后仍然能看懂主体是什么。

---

## 4. 色彩规则

整体采用：

**深色背景 + 单一主色 + 白色高光核心。**

常见颜色映射：

| 技能属性 / 类型 | 推荐主色 | 视觉感觉 |
|---|---|---|
| 火焰 / 爆炸 | 橙、红、金黄 | 炽热、爆裂、伤害高 |
| 物理冲击 / 斩击 | 橙红、金黄、白光 | 力量、速度、打击感 |
| 雷电 | 紫、蓝紫、亮白 | 爆发、麻痹、能量感 |
| 冰 / 水 | 蓝、青、白 | 冷感、冻结、防御 |
| 风 | 绿、青绿、浅青 | 速度、旋转、切割 |
| 毒 / 腐蚀 | 绿、黄绿、暗紫 | 腐蚀、持续伤害 |
| 圣光 / 治疗 | 金、黄、白 | 神圣、祝福、恢复 |
| 暗影 / 诅咒 | 黑、紫、暗蓝 | 神秘、邪能、控制 |
| 空间 / 星辰 | 蓝紫、粉紫、白 | 魔法、传送、虚空 |
| 精准 / 命中 | 金、白、橙 | 瞄准、锁定、穿透 |

注意：

- 每个图标最好只有一个主色系。
- 辅色不要太多，否则 64×64 会变脏。
- 高光区域可以使用白色或接近白色。
- 背景优先使用黑、深紫、深蓝、深棕。

---

## 5. 构图规则

### 5.1 中心主体放大

主体应该尽量大，最好接近图标边缘。

推荐构图：

- 中心圆形能量球
- 巨大的斩击弧线
- 大面积火焰爆发
- 大型符文/法阵
- 明确的人物剪影
- 明确的飞弹轨迹

避免构图：

- 主体太小，周围留太多空白。
- 多个小物件平均分布。
- 背景过于复杂，抢主体。

### 5.2 斜向运动感

很多技能图标适合使用斜线构图：

- 左下 → 右上：突进、飞弹、上升、强攻击。
- 右上 → 左下：坠落、劈砍、轰击。
- 中心向外：爆炸、冲击波、范围伤害。
- 环形旋转：护盾、旋风、持续法术。

斜向构图能显著增强速度感和技能释放感。

### 5.3 中心爆光

推荐在主体背后加：

- 径向爆光
- 放射线
- 模糊光晕
- 速度拖尾
- 粒子飞散

这样图标在 War3 面板里会更亮、更醒目。

---

## 6. 造型规则

这套风格不追求真实结构，而追求**符号化识别**。

常见主体设计：

| 技能概念 | 推荐表现方式 |
|---|---|
| 斩击 | 弯月形能量刃、交叉刀光、锐利光弧 |
| 飞弹 | 长条光束、尾焰、拖尾、冲刺线 |
| 爆炸 | 尖刺火焰、中心白光、向外放射 |
| 护盾 | 圆球、环形法阵、透明能量罩 |
| 雷电 | 电弧、紫色人体轮廓、分叉闪电 |
| 冰 | 冰晶、蓝白尖刺、冻结光环 |
| 风 | 绿色旋风、环形气流、弧形切割线 |
| 毒 | 绿色烟雾、腐蚀液体、尖锐毒痕 |
| 圣光 | 金色十字、光环、瞄准圆环、太阳纹 |
| 暗影 | 黑色剪影、紫色眼睛、暗影手势、虚空裂口 |
| 召唤 | 手势、法阵、灵魂剪影、紫黑旋涡 |
| 控制 | 锁链、眼睛、符文、束缚光环 |

核心原则：

**一个图标只表达一个核心概念。**

例如：

- “雷霆护体”：不要同时画人、盾、雷龙、法阵、文字；可以只画“紫色人形剪影 + 雷电外轮廓”。
- “火焰斩”：不要画完整人物挥剑；可以只画“橙红交叉斩击 + 火焰拖尾”。
- “冰爆”：可以只画“蓝白冰晶中心爆裂”。

---

## 7. 光效规则

推荐光效层级：

1. 暗色背景
2. 背景模糊光晕
3. 径向爆光 / 速度线
4. 主体能量形状
5. 主体外发光描边
6. 白色核心高光
7. 少量粒子、星点、碎片

常用光效关键词：

- strong outer glow
- neon glow
- radial burst
- bright white core
- motion trails
- energy particles
- speed lines
- luminous aura
- high contrast lighting

注意：

- 外发光要明显。
- 主体边缘要亮。
- 中心或攻击点可以使用白色高光。
- 粒子不能太多，避免小尺寸糊掉。

---

## 8. 线条与细节规则

推荐：

- 干净线条
- 夸张轮廓
- 锐利边缘
- 简化形状
- 赛璐璐色块
- 强烈剪影
- 少量关键细节

避免：

- 写实纹理过多
- 金属/皮革材质细节过多
- 复杂背景故事元素
- 小字、小符号、小装饰
- 过多渐变导致主体发糊
- 主体边界不清楚

一句话：

**看起来可以华丽，但结构必须简单。**

---

## 9. 背景规则

背景通常不是重点，但要帮助主体突出。

推荐背景：

- 黑色
- 深紫
- 深蓝
- 深棕
- 暗红
- 暗绿色
- 径向暗角
- 简单模糊能量纹

背景处理：

- 四角压暗。
- 中心略亮。
- 背景可以有速度线，但不能抢主体。
- 不要使用复杂场景。
- 不要画地面、天空、建筑等大场景，除非技能概念必须表达。

## 12. 反向 Prompt / 避免项

生成图标时建议加入以下限制：

```text
no text, no letters, no numbers, no logo, no watermark, no realistic photo, no detailed background, no tiny details, no complex scene, no multiple small objects, no blurry subject, no low contrast, no dull colors
```

中文理解：

- 不要文字
- 不要数字
- 不要水印
- 不要写实照片感
- 不要复杂背景
- 不要过多小细节
- 不要多个小主体
- 不要主体模糊
- 不要低对比
- 不要灰暗脏色

---

## 13. 生成前检查清单

每次生成 War3 技能图标前，检查：

- [ ] 是否是正方形图标？
- [ ] 是否适合 64×64 小尺寸？
- [ ] 主体是否占画面 70% 以上？
- [ ] 是否没有文字？
- [ ] 是否没有复杂小细节？
- [ ] 主体轮廓是否清晰？
- [ ] 背景是否足够暗？
- [ ] 主体是否足够亮？
- [ ] 技能属性是否能通过颜色快速判断？
- [ ] 是否有强外发光？
- [ ] 是否有速度感或爆发感？
- [ ] 缩小后是否还能一眼看懂？

## 14. 后续制作时的推荐格式

用户给技能需求时，可以按这个格式描述：

```text
技能名：
技能属性：火 / 雷 / 冰 / 风 / 毒 / 圣光 / 暗影 / 物理 / 护盾 / 召唤
技能核心概念：例如“向前斩出一道火焰刀光”
图标主体：例如“橙红色斜向火焰斩击”
颜色：例如“橙红 + 白色高光 + 黑紫背景”
是否需要人物剪影：是 / 否
备注：不要文字，64×64 小尺寸清晰
```

示例：

```text
技能名：焚天斩
技能属性：火 / 物理
技能核心概念：向前斩出一道燃烧刀光
图标主体：橙红色斜向火焰斩击，占画面大部分
颜色：橙红、金黄、白色高光，暗红黑背景
是否需要人物剪影：否
备注：不要文字，强调速度感和爆发感，64×64 清晰
```

## 15. 最终风格总结

这套 War3 二次元技能图标的本质是：

> **用暗色背景承托高饱和能量主体，用强发光和夸张剪影提升小尺寸识别度，用简化符号表达技能功能。**

最重要的不是复杂，而是：

**亮、准、大、清楚、有冲击力。**
