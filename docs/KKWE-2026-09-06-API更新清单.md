# 2026-09-06 KKWE API 更新清单

来源：本次更新前后的 YDWE/jass 四组 API 声明差异；中文名称引用 MPQ/kkapi/action.txt、call.txt、event.txt。正式/PRE 状态按声明所在文件判断。

新增 125 个接口（全部位于 KKPRE，正式服目前不可用），98 个接口由 KKPRE 转入 KKAPI，无接口删除。BlizzardAPI、DzAPI 无新增声明。

验证：War3Lib VERSION_UNITTEST / Museum / vjassc 编译成功；DzFrameGetName、DzIsWindowActive 仅在 BlizzardAPI 登记。
