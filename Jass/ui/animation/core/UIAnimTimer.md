# uianim：本地 UI 动画时钟

`create(code)` 仍须在同步初始化中调用；`reg()` / `unreg()` 启停本机的表现更新。回调可以播放、收尾或销毁 UI，但不能根据本机完成时间改变同步游戏状态。

唯一驱动是 `hardware.regUpdateEvent`。有活动项时，每帧用 `100.0 / DzGetFPS()` 估计经过的秒数，累计满 0.02 秒派发一步，余数留到下一帧。无效 FPS 沿用最近的有效估计（初始 0.02 秒）；单帧最多计入 0.16 秒，避免严重卡顿后集中执行大量 UI 回调。空闲时不累计欠下的步数。它用于暂停中也要继续的视觉动画，不是精确的墙钟或游戏计时器。

每个逻辑步从当步活动列表生成快照。注销立即取消尚未执行的回调；新增或重新注册从下一逻辑步起生效，下一步可能仍在同一绘制帧内。即使回调把自己从紧凑表移除，尾部换位的其他动画也不会漏掉该步。
