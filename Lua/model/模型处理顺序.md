完成材质、动画和附加点后，运行模型第5步合并顶点：
D:\War3\Library\War3Lib\Lua\model\模型第5步_合并顶点.lua
修改脚本顶部 flag.path，或用命令行传入目标文件：
lua "D:\War3\Library\War3Lib\Lua\model\模型第5步_合并顶点.lua" "D:\素材\模型.mdx"
支持经典 Version 800 的 MDX 和 MDL；MDL 需要 flag.converterExe 指向 war3mdlx.exe，处理后会重建文本。
MDL 使用能还原相同 float32 位模式的短小数，避免完整小数展开导致文本膨胀；已经合并过顶点的 MDL 也可单独缩短小数。
MDL 写回前会验证往返结果；仅允许 BONE/HELP 动画浮点字段中的 -0 与 0 等价变化，实际数值、帧时间和 ID 变化仍会拒绝写回。
可先追加 --dry-run 只查看预计收益；追加 --keep-normals 可对所有材质保留法线差异。
默认只在材质每一层均为 Unshaded 且没有 SphereEnvMap 时合并不同法线；其他材质只合并全部属性一致的顶点。
位置、所有 UV 和有效骨骼组必须完全相同，不减面、不抽动画帧，也不跨 Geoset 合并。
有变化时自动备份为“原路径.bak.时间戳”再覆盖；无收益时不写回。MDX 的非网格数据逐字保留。
输出会打印各 Geoset 的顶点变化和预计 MDX 大小；合并后仍需进游戏检查外观。
